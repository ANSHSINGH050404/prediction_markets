# prediction_markets

Prediction markets platform — multiple markets, trading, and settlement.

## Stack

Next.js, Prisma, TypeScript

## Getting started

```bash
git clone https://github.com/ANSHSINGH050404/prediction_markets.git
cd prediction_markets
npm install
npm run dev   # or: npm start
```
